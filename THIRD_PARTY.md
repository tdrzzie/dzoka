# Third-party dependencies

Dzoka's original core code is MIT. That grant does not replace dependency licenses. The committed [artifact lock](dependencies.lock.json) records 106 exact runtime/test coordinates, SHA-256 digests, declared licenses, selected alternatives and embedded notice digests. The [adoption index](docs/dependencies/README.md) links foundation and intake/media architecture/license reviews.

Spring, Tomcat, Jackson, HikariCP, Nimbus, Micrometer, SnakeYAML, Flyway and Apache support libraries use their recorded Apache-2.0 grants. PostgreSQL JDBC is BSD-2-Clause; SLF4J and Checker annotations use MIT; Logback and Jakarta annotations use the recorded EPL-2.0 alternative. JUnit is EPL-2.0 and test-only. Refer to the exact artifact/POM evidence rather than treating these family names as a blanket license decision for future versions.

Nested dependency JARs retain their supplied licenses/notices when packaged. Preserve those and provide this inventory when redistributing the core. A full redistribution/NOTICE bundle and expanded build-tool/transitive advisory SBOM remain release work; this foundation is not a production distribution.

JDKs and the external PostgreSQL test image have separate runtime/component terms described in the adoption record; they are not bundled into the core JAR. No audited GPL/AGPL, unresolved-license or all-rights-reserved project source has been copied into the permissive core.

AWS SDK for Java S3/URLConnection and its recorded SDK modules use Apache-2.0; Reactive Streams 1.0.4 uses MIT-0. Preserve their embedded notices. SeaweedFS 4.51 is an external Apache-2.0 disposable test server. The isolated Temurin JRE image has GPLv2/Classpath Exception and separate component/base-system terms; it runs outside the MIT core. Exact versions/digests, inspected source scope and native archive verification are recorded in [intake/media adoption](docs/dependencies/intake-media-adoption.md). These bounded reviews do not establish production advisory clearance or a complete distribution notice bundle.

The separate M4 Python environment has 21 locked wheels in [runtime inventory](ai/runtime.lock.json). ONNX Runtime is MIT; Tokenizers/Hugging Face components and FlatBuffers are Apache-2.0; NumPy and native components retain their bundled terms, including GCC runtime-exception notices. Other selected grants include MIT, BSD-3-Clause, PSF-2.0 and unmodified external tqdm's MPL-2.0 AND MIT. The separately downloaded model publisher declares Apache-2.0 for the pinned weights/tokenizer. Preserve each artifact's notices and resolve complete binary redistribution obligations; Python/native/model code is not copied into the MIT Java core. [Text inference adoption](docs/dependencies/ai-text-adoption.md) records exact scope and limitations.
