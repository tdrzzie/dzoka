## Known debt

These are bounded static source reviews with explicit subsystem limitations, not certification of all upstream behavior, security, dependencies, weight licensing, durability, compatibility or measured performance. Registry checks validate metadata and manifests, not the truth of review conclusions. Unresolved/restrictive grants require independent implementation or separate permission before source reuse. The [remaining gaps](docs/source-audit/findings/unresolved-gaps.md) track integration, policy, privacy, calibration and runtime validation. Supplied historical research remains partly duplicative. Confidential security/conduct contacts and response procedures need establishment before release.

Implementation limitations: tenant/membership/model-space administration remains an authorized operator/database task. Organization listing is bounded at 100 without full pagination. No live Kafka transport, production IdP lifecycle, financial/courier integration, backup/restore drill, full advisory scanner or redistribution/NOTICE bundle is delivered. Private images remain a bounded S3/PNG/JPEG profile. The real AI provider is a scoped local text profile, not complete multimodal fingerprints, calibrated multilingual quality, retrieval or ownership verification. Native runtime isolation/egress controls, additional platforms, complete snapshot promotion/rollback and production scheduling remain. A crash/revocation between a late object write and its DB acknowledgment can leave inaccessible orphan bytes; independent bucket/tombstone reconciliation and backup/replica erasure are required. Row context does not protect against arbitrary SQL with stolen runtime credentials. Expanded build-tool SBOM/advisory review remains release work.
