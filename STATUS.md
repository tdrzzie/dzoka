## Known debt

These are bounded static source reviews with explicit subsystem limitations, not certification of all upstream behavior, security, dependencies, weight licensing, durability, compatibility or measured performance. Registry checks validate metadata and manifests, not the truth of review conclusions. Unresolved/restrictive grants require independent implementation or separate permission before source reuse. The [remaining gaps](docs/source-audit/findings/unresolved-gaps.md) track integration, policy, privacy, calibration and runtime validation. Supplied historical research remains partly duplicative. Confidential security/conduct contacts and response procedures need establishment before release.

Implementation limitations: tenant/membership/model/profile administration remains an authorized operator/database task. Organization listing is bounded at 100 without full pagination. No live Kafka transport, production IdP lifecycle, financial/courier integration, full advisory scanner or complete redistribution/NOTICE bundle is delivered. Logical database restore is verified; coordinated object/key/role disaster recovery, tombstone replay, PITR and HA remain. Inputs are preserved report text, private PNG/JPEG derivatives, strict short PCM WAV and bounded private caller-supplied rerank envelopes; arbitrary media/documents remain unsupported. Real local providers and multimodal pins now work, but ResNet signatures/classical patches/axis-aligned OCR/English CTC are bounded profiles. The earlier ResNet profile remains distinct from the new bound Jina joint space. These do not establish learned local features, universal speech/OCR quality, instance segmentation, calibrated retrieval or ownership verification. Rollouts support 100 reports/16 text spaces plus 64 perception pins; first activation excludes noncohort/new-revision evidence and reads serialize with transitions. Evaluation digests identify approval references, not proof of quality. Additional native platforms, OS memory/CPU/egress enforcement, larger-cohort/index migration and scheduling remain. A crash/revocation between a late object write and its DB acknowledgment can leave inaccessible orphan bytes; independent bucket/tombstone reconciliation and backup/replica erasure are required. Row context does not protect against arbitrary SQL with stolen runtime credentials. Expanded SBOM/advisory/notice work remains before redistribution/production.
