# 0062. Source regions and masked edge evidence

- Date: 2026-11-26
- Status: Accepted for the bounded local edge profile

Whole-frame downscaling can erase a small item before appearance matching. Allow an explicit `sourceRegion` on indexed compressed samples. It is an integer `[x,y,width,height]` rectangle in native source pixels, bound by the registered archive digest and therefore the camera identity and investigation approval. Apply it before the existing 320 by 240 output bound. Unspecified regions preserve the earlier whole-frame behavior. Reject malformed, excessive and out-of-source regions rather than silently clamping them. Keep the region in frame-cache identity and evaluation provenance. Clip hashes, sample offsets and the approved archive preserve the mapping to original evidence. Decoding keeps the same pinned optional FFmpeg process, licenses and isolation limits from ADR 0061. No dependency or model weight is added.

Crop export requires a `disclosureMask` in the exact reviewer-approved search plan. Its binary rows match the reference template dimensions. Translate that fixed object mask with each detected reference box and replace every outside pixel with zero before upload. Plans without a mask remain valid for metadata observations but export no pixels. This reduces disclosure and intentionally changes earlier plans that exported rectangular crops. A changed plan needs fresh reviewer approval. A mask cannot compensate for a wrong match, changing viewpoint or an inaccurately drawn object boundary. Independent crop review and grant revocation remain required; this is not automatic semantic privacy certification.

Core derives possible-disappearance windows from adjacent, chronological point observations with the same processor identity. Unknown gaps, interval observations and processor changes do not establish a window. Return both endpoint source digests and label the window as a hypothesis. Derive it from the persisted result on each authorized read, preserving report availability, tenant scope, expiry, revocation and purging. No schema migration or custody mutation is required.

Transition evaluation additionally rejects reused source evidence and a model as-of cutoff at or after evaluation observations. Report multiclass Brier error, available-case coverage, unseen destinations and source-state slices. Time-error metrics explicitly cover correct top-one completed transitions only. Completed-transition records cannot establish censored-event behavior or calibrated probabilities. The new evaluation format does not change prior model bytes or approve a runtime rollout.
