# 0050. Measure bounded local model workloads without claiming production capacity

- Status: Accepted scoped implementation; full local execution verified, production acceptance remains separate
- Date: 2026-11-17

After the mandatory source gate, add an optional standard-library management tool for serial local model-path measurements on the current account. Existing native conformance establishes execution and recovery, not capacity. Keep all historical inference/model/runtime/profile/service identities and dependencies unchanged. Stage a new immutable receipt-verified management release. Shona is excluded from this tool's explicit profile allowlist and remains deferred.

An operator freezes a protected hash-bound workload with host/workload authority evidence, exact reviewed non-Shona profile keys and original input bytes. Admit at most four entries/twelve total calls, two warmups and eight measured samples per entry, with a bounded explicit admission budget. Check every input before any inference. Use fresh independent private state and an exclusive state-owner lock. Run serially; every call uses a fresh existing confined model process. Warmups may affect OS caches but do not establish a persistent loaded model. Full initial bundle verification is outside sample timing; sample timing includes confinement, inference, cleanup and post-call boundary checks. This is not HTTP/DB queue latency, saturation throughput, a concurrent scheduler or a load-test SLO.

Preserve AVAILABLE, UNAVAILABLE, cleanup/integrity UNCONFIRMED, budget NOT_DISPATCHED and interrupted/unobserved coverage separately. Never retry a failed sample invisibly. No further inference follows unconfirmed cleanup/integrity. The admission budget gates new dispatch only; existing reviewed per-invocation deadlines still bound in-flight work. It is not a hard whole-process watchdog. Missing provider truncation flags stay unknown. Report nearest-rank percentiles of available samples with their sample counts; sparse observations are not population tails or independent quality examples.

Exclusively create a protected hash-chained JSONL execution ledger, flushing each event. Keep START, each CALL and terminal SUMMARY/ABORT rather than replacing earlier evidence. A missing terminal event is incomplete. Caller-retained whole-ledger hashes are necessary: the chain alone does not prevent an authorized operator rewriting history. Omit raw inputs/outputs, private labels, exception details and host identity; retain input/output/source/profile/release/host-evidence hashes. Always leave quality NOT_EVALUATED, SLO/approval NOT_ESTABLISHED and property release NOT_GRANTED. No fingerprint or production configuration changes follow.

Alternatives: production load claims from one synthetic model call would be unsupported; concurrent model deployment requires its own scheduling/resource and grant-lifecycle design; general benchmark frameworks would add unreviewed dependencies. The bounded collector supplies reproducible local evidence now, with representative workload/capacity requirements, end-to-end load testing, wider profiles and unattended/target-host acceptance remaining separate work. Verify integrity failures, unavailable/truncated coverage, warmup separation, budget exhaustion, exclusive output/ownership and cleanup aborts. Native checks must exercise real isolated non-Shona inference and protected CLI/ACL boundaries, retaining all original failures.

The [November 17 execution record](../testing/m4-model-capacity-2026-11-17.md) preserves the first full-run readiness failure and a corrected complete 27-phase pass. Test-only generation-aware readiness observations expose actual initial/watchdog/explicit waits; changed diagnostic/controller/test-JWT bounds do not change deployed worker policies, model identities or production token/lease rules, and do not identify or repair the original transient startup-delay cause. That remains local operational debt.
