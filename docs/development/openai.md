# Direct OpenAI public-reference connection

This separate optional connection follows [ADR 0052](../adr/0052-direct-openai-public-reference-connection.md). OpenRouter and local providers retain their existing configuration. There is no automatic fallback or private/core-job integration.

Run `python -B tools/openai_connection.py setup` once under the current Windows account. It refuses existing directories. Put an OpenAI API key in the `apiKey` string in `C:\Users\nyash\DzokaOpenAI\credentials.json`. Never paste it into chat or commit it. Explicit model/limits and the enabled flag live in the adjacent `settings.json`. Setup defaults disabled; this user's requested reference test is now enabled after authenticated model access. No `.env` file is used.

`python -B tools/openai_connection.py check` checks authentication/model access without sending reference text. `reference --input <protected-public-envelope.json> --output <new-private-result.json>` uses the same hash-bound public-reference input fields as [OpenRouter](openrouter.md). It exclusively reserves an uncertain-attempt receipt before a paid request. Never delete that receipt to repeat an uncertain charge; reconcile it or deliberately choose a new attempt. All output receipts explicitly disable inherited ACLs before content is written.

Current model: `gpt-6.1-terra`, low reasoning, 1,024 maximum output tokens, 180-second transport deadline. Official November 18 prices list $1/million input and $5/million output tokens; account usage is authoritative. No whole-request spend ceiling or Shona accuracy guarantee is implied. Requests specify `store:false`; this is not an account-level Zero Data Retention attestation. See [model](https://developers.openai.com/api/docs/models/gpt-6.1-terra) and [data controls](https://developers.openai.com/api/docs/guides/your-data).

The November 18 live public greeting returned `Mhoro, nyika!` for `Hello, world!`, without truncation. This is a smoke test only. Results remain private with exact client/config/prompt/input identities. Representative bilingual and code-switch comparisons remain required before quality acceptance. No translation authorizes property release.

To replay a Shona reference with the optional fidelity prompt, pass a separate protected settings file with `--config`. Copy the schema 1 fields, set `schemaVersion` to `2`, and add `"promptVersion": "openai-shona-fidelity-v2"`. It uses the same credentials file in the settings directory. Use a new output path. Schema 1 continues to select the original prompt. The fidelity prompt improved the authored code-switch slice and regressed both sampled English-to-Shona cases, so it remains a development option. [Matched evaluation](../testing/openai-shona-matched-2026-11-18.md).

For English-to-Shona diagnostics, schema 2 also accepts `"promptVersion": "openai-english-to-shona-v3"`. The prompt targets standard written Shona and rejects other language directions. It remains opt-in after mixed held-out results. [Results and plan](../testing/openai-en-sn-heldout-2026-11-18.md).
