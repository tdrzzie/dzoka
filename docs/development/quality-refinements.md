# Versioned local quality alternatives

[ADR 0043](../adr/0043-versioned-quality-refinements-and-optional-reference-api.md) and the [artifact review](../dependencies/m4-refinement-adoption.md) govern this generation. No new runtime package is installed: the providers use the existing reviewed 22-wheel CPU environment. Model artifacts remain outside Git and are checked against `ai/refinement.lock.json` before native sessions. Do not download artifacts implicitly during inference.

`ai/refinement-profiles.json` contains 18 explicit candidates: twelve M2M100 translation directions, three dedicated Marian directions, Whisper Tiny English transcription, Mask R-CNN COCO detection and a VOC-compatible semantic union of its instance proposals. The translation variants use 256 input/128 output token bounds and declared unknown-token suppression. They preserve unavailable/all-unknown input, truncation flags, raw source and UNVERIFIED_TRANSLATION trust. Longer output is not evidence of better meaning.

Whisper accepts the existing strict mono PCM16/16kHz, ten-second input contract. Its pinned original mel coefficients, periodic Hann frontend and cached greedy decoder are explicit configuration. Silence, invalid shapes, nonfinite tensors, missing EOS and empty output fail closed. English transcription does not establish Shona speech support. The first retained narrowband digit diagnostic was wrong; this candidate must not be represented as an accepted quality improvement.

Mask R-CNN uses bounded aspect-preserving BGR/mean-subtracted padded inputs. Contiguous model IDs map explicitly to COCO-90. Detection retains at most twenty proposals above the declared threshold, with source-pixel boxes. Segmentation maps supported classes to VOC-21 and unions thresholded ROI masks at the existing 64-grid sample locations; unsupported classes remain background. This representation does not expose full instance identities. Background agreement alone cannot demonstrate useful segmentation.

The broker source boundary changed. All 52 current isolated identities are a new generation, including the previous 34 tasks. Historical metadata and exact critical sources are retained under `ai/history/broker-v1-20261106/`; existing immutable private releases are preserved. The archive is source evidence, not a standalone complete installation. Persisted components/profile rows are never rewritten. Register new profiles/spaces disabled in an application deployment, evaluate explicit versions and use the existing authorized cohort promotion process. Regenerating a registry does not activate it or approve its output.

Prepare new absolute owner-private model and management directories using the existing `broker_bundle.py` and `managed_release.py` commands; never alter a published bundle. Pass both exact receipts to `verify_local.py`. The full gate runs all isolated profiles, actual HTTP/JWT completion, source/model/runtime integrity, Docker raster/CPU Shona boundaries and database restore. The expanded tests cover new transcription/translation broker completion and new region completion over sanitized private image leases. Authored fixtures establish conformance only.

For a narrower `test_intake.py --with-broker` diagnostic, also pass `--with-perception` to generate the authored voice fixture, or supply an explicit `DZOKA_TEST_SPEECH_WAV` path to an equivalent permitted PCM fixture. Broker transcription tests require that input and fail when it is absent; the full gate already supplies it through `--with-perception`. A narrower diagnostic cannot replace the full matrix.

Keep public-reference diagnostic outputs private, retain selection/source/configuration/output identities, distinguish previously inspected development examples from newly selected rows, and report unavailable/truncated cases. Unknown checkpoint training overlap prevents a training-disjointness claim. Qualified language/geometry review and accountable tolerances remain required before promotion. [OpenRouter](openrouter.md) is a separate optional public-reference client, disabled until explicitly configured; local inference cannot silently fall back to it.
