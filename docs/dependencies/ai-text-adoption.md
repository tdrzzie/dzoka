A private Python leased-job consumer receives only its authorized normalized report text and submits derived envelopes; it has no database, object-store, ownership or release authority.

This separately distributed native runtime is not GPL implementation source incorporated into the MIT core. Keep all bundled notices and complete redistribution obligations before shipping binaries. The resolved HTTP/HF utilities are dependency obligations, not authorization for runtime network model downloads.

Only hash-locked wheels, never source-build hooks, may enter the isolated `.audit-cache` environment. Verified host CPython is 3.14.7, Windows amd64; other platforms need their own wheel/license/native conformance review even though the requirements file includes publisher hashes for release wheels. No package or model is activated just because it resolves. Preserve wheel licenses/notices and review/update advisories before production; this is not full transitive source/security certification. The implementation must demonstrate checksum rejection, real nonconstant inference, bounded finite normalized output, missing-provider failure, immutable space/input provenance and stale/cross-tenant completion rejection before claiming the scoped provider verified.

Advisory review on 2026-10-26 consulted the official [ONNX Runtime 1.31.0 release](https://github.com/microsoft/onnxruntime/releases/tag/v1.31.0) and [Tokenizers](https://github.com/huggingface/tokenizers/security/advisories)/[NumPy](https://github.com/numpy/numpy/security/advisories) security pages. Whole-runtime advisory scanning, native isolation/egress enforcement and deployment-specific resource/security assessment remain open before production activation.
