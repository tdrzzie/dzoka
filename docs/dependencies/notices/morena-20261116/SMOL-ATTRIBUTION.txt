Diagnostic transformations: select SmolSent Shona/English rows 1-8 per
direction as additional tests and rows 257-259 per direction as separate
three-shot context. Preserve each selected source/target string unchanged;
encode context strings in a first-party length-framed binary asset.
The two files are reverse-direction pairs, not independent translations.
Exact whole-file, row-content and context hashes are retained in the data
records/private manifest. No model fine-tuning or upstream loader is used.
The corpus and generated translations are not redistributed in this archive.
