The mandatory source gate passed. The [pgvector source audit](../source-audit/retrieval/pgvector.md) covers the SQL cosine operator, filtered retrieval, index and packaging surfaces. For the disposable Linux amd64 conformance database use the [official v0.8.7 release](https://github.com/pgvector/pgvector/releases/tag/v0.8.7) PostgreSQL 18 Trixie image. The official tag `0.8.7-pg18-trixie` resolves to the OCI index `sha256:ab49524d18df7200b74ac9a475e1db6297fc1eb57da4c214c63d10ecc4b754fa`. Pin the amd64 manifest `sha256:a5b06db72c44033b10fde7f303aad2a543e87a314dd6c2a680848067defd3760` to execute it. The [release license](https://raw.githubusercontent.com/pgvector/pgvector/v0.8.7/LICENSE) is the PostgreSQL License. No binaries, source or notices from the image are redistributed by Dzoka.

Approval is limited to a disposable synthetic integration database with an exact image digest, random credentials, loopback publication and no host mounts. The extension must reside in the administrator-governed `public` schema and report the reviewed release. Ordinary core credentials cannot install or update it. This review does not approve a production image, shared-host installation, package inventory or unattended upgrade. A deployment review must confirm transitive notices, advisories, extension ownership, indexing/maintenance and backup compatibility on the chosen target. The native exact backend remains available independently of this extension.
