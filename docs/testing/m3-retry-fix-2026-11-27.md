2026-11-27. This execution supersedes the local retry defect in the [post-publication recheck](m3-post-publication-recheck-2026-11-27.md). The historical failed probe remains intact.

## Implemented behavior

V28 classifies existing place-command receipts as hash version 1 without rewriting their original digest or result. New receipts explicitly use version 2: domain-separated, length-framed UTF-8, fixed field order and nullable fixed-width numeric values. The digest no longer depends on JSON map iteration or the injected mapper. Both historical outer-map JSON orders remain readable through a private frozen projection. Changed bodies and unknown versions fail closed; authorization, tenant/actor scope, historical results and atomic audit/outbox retain their existing boundaries. No new runtime dependency is added.

[ADR 0068](../adr/0068-stable-place-command-receipts.md) and the [upgrade/API guide](../development/places-and-media-reconciliation.md) define the format and controlled rollout. Drain old binaries before the schema/application upgrade; mixed old/new binaries and downgrade after writing version 2 receipts are unsupported.
