It adds protected manufacturer serial attestation, lexical and spatial/time retrieval, exact vector retrieval, reciprocal rank fusion, bounded deterministic evidence reranking, explicit route and response caps, and separate similarity, coverage and hard conflict disposition. The query returns opaque references and evidence metadata. Live confidence remains uncalibrated.
